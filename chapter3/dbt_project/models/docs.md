### ナビゲーション

ウィンドウの左側にある `Project` と `Database` のナビゲーションタブを使用して、プロジェクト内のモデルを探索できます。

#### Project タブ

`Project` タブは、dbt プロジェクトのディレクトリ構造を反映します。このタブでは、dbt プロジェクトで定義されたすべてのモデルと、dbt パッケージからインポートされたモデルを確認できます。

#### Database タブ

`Database` タブも同様にモデルを表示しますが、データベースエクスプローラーのような形式で表示されます。このビューでは、データベーススキーマにグループ化されたリレーション（テーブルとビュー）が表示されます。なお、エフェメラルモデルはデータベースに存在しないため、このインターフェースには表示*されません*。

### グラフ探索

ページの右下角にある青いアイコンをクリックすると、モデルのリネージグラフを表示できます。

モデルページでは、探索中のモデルの直接の親と子が表示されます。このリネージペインの右上にある `Expand` ボタンをクリックすると、探索中のモデルの構築に使用されるすべてのモデル、または探索中のモデルから構築されるすべてのモデルを確認できます。

展開後は、`--select` と `--exclude` のモデル選択構文を使用して、グラフ内のモデルをフィルタリングできます。モデル選択の詳細については、[dbt 公式ドキュメント](https://docs.getdbt.com/docs/model-selection-syntax)をご確認ください。

また、モデルを右クリックして、インタラクティブにフィルタリングおよびグラフを探索することも可能です。

# Jaffle Shop

`Jaffle Shop` は [dbt Labs が公開する学習用の dbt プロジェクト](https://github.com/dbt-labs/jaffle-shop) で、Jaffle (ホットサンドの一種) を提供する架空レストランの注文データを題材としています。
本書では、ハンズオンの題材としてデータを一部利用しますが、ハンズオンのコードは dbt Labs が提供するものとは異なります。

## データモデルの概要

本プロジェクトは staging / marts の 2 レイヤー構成です。

- **staging**: ソースの生データに対して、型変換・カラム名の統一・軽微なクレンジングを行う view レイヤー。
- **marts**: BI ツールや分析者が参照する table レイヤー。顧客ディメンション `customers` (1 行 1 顧客) と、注文ファクト `orders` (1 行 1 注文、明細の集計を含む) の 2 モデルを提供します。

## 注意事項

- 本プロジェクトのデータはすべてサンプル (架空のレストラン) であり、実在の店舗・顧客とは関係ありません。
- 金額は円 (整数) で扱う想定です。税率などの業務要件は簡略化しています。
